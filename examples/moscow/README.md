# Москва — Покровка / Чаплыгина / Лялин переулок

Выбран реальный узел OpenStreetMap 960745895: 55.7610685, 37.650596.
Данные OSM получены 13 ноября 2026 года. Это упрощённая модель одного перекрёстка.
Интенсивности — демонстрационные, не натурные измерения. Светофорные программы построены SUMO, не получены от реального контроллера.

- `area/report.html`: инфраструктура вокруг Покровки.
- `model/scenario.sumocfg`: исходная SUMO-модель для показа.
- `plans/optimized/scenario.sumocfg`: план с проверенными ограничениями.
- `plans/optimized/report.html`: длительности и проверка зелёного/жёлтого/красного.
- `geometry.json`: улицы и геометрия для воспроизводимости.

Запуск: `sumo-gui -c examples/moscow/model/scenario.sumocfg`.
Панель: `.\.venv\Scripts\python.exe -E -X utf8 ui/control_panel.py`.
Предыдущий пример сохранён в runs/before_moscow_…; теперь в рабочей панели выбран московский перекрёсток.
