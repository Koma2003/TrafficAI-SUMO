## Установка

Python 3.10+, SUMO с `sumo`, `sumo-gui`, `netconvert` в PATH.

```sh
pip install -r requirements.txt
pip install traci
# Необязательно, для быстрого обучения без TCP:
pip install libsumo
```

Версии libsumo/traci должны соответствовать установленной версии SUMO. Если встроенный libsumo не импортируется, установите wheel для вашей версии Python в виртуальное окружение. Для всех команд ниже рабочая папка — корень репозитория.

## Выделение района в интерфейсе

```sh
python ui/control_panel.py
```

1. Нажмите **«Район и отчёт»**.
2. На карте через ПКМ выберите **«Угол области для отчёта»** дважды — в противоположных углах прямоугольника. Альтернатива: введите южную/западную/северную/восточную границы в окне.
3. **«Показать границы»** рисует оранжевую рамку. Ограничение примера — 25 км².
4. Нажмите **«Сформировать отчёт»**. После получения данных откроется HTML. Файлы сохраняются в `runs/area_ДАТА_ВРЕМЯ/`.

Получение данных — Overpass API, кэш 24 часа. При перегрузке сервиса показывается ошибка; готовые примеры остаются доступны офлайн. Инвентаризация включает 6 основных категорий и прочие объекты. Здание и POI внутри могут учитываться отдельно; число объектов не равно посещаемости или населению. Источник геоданных — © OpenStreetMap contributors, ODbL.

CLI с реальными данными:

```sh
python -m osm.area_analysis --bbox 54.789 55.874 54.794 55.882 --output runs/my_area
```

Офлайн-проверка без интернета:

```sh
python -m osm.area_analysis --bbox 54.787 55.873 54.797 55.883 --input examples/area_fixture.json --output runs/offline_area
```

Отчёт формируется по фактам, без LLM и без API-ключа. LLM-адаптер — следующий этап; текущая версия не делает выводов о дефиците инфраструктуры без данных населения и нормативов.

## RL: диапазоны зелёного, жёлтого и «всем красный»

Подготовьте воспроизводимый автомобильный перекрёсток:

```sh
python examples/create_signal_demo.py
```

В интерфейсе кнопка **«RL / фазы»** открывает диапазоны и количество эпизодов. Учебный запуск работает в фоне через TraCI, пишет `runs/rl/training.log` и по завершении открывает отчёт. При работе через TraCI обучение может быть медленнее, чем через libsumo.

Быстрый CLI-пример:

```sh
python sumo/rl_signals.py --backend libsumo --episodes 30 --green-min 15 --green-max 45 --yellow-min 3 --yellow-max 5 --red-min 2 --red-max 4 --output runs/rl
```

Без libsumo уберите `--backend libsumo`. Зелёный выбирается с шагом 10 с (плюс верхняя граница), жёлтый и «всем красный» — с шагом 1 с. Шаг зелёного можно изменить через `--green-step`. Изменение диапазонов не требует правки кода. Жёлтый не может быть короче исходного жёлтого в сети.

**Красный здесь — отдельная фаза «всем красный», между жёлтым и следующим зелёным.** Красный конкретного направления складывается из фаз остальных направлений. Его независимый минимум/максимум эта версия не задаёт.

Контроллер сохраняет состояния разрешённых направлений исходной сети и учится выбирать длительности. Состояние Q-learning — номер фазы и дискретизированные очереди подходов. Награда — отрицательная сумма очереди и числа автомобилей, ожидающих въезда, за интервал действия. Для действий разной длины используется временное дисконтирование. Сравнение проводится на отдельном seed с одинаковым спросом.

Сохранённый пример: стоимость фиксированного плана **2143 авто·с**, RL **1731 авто·с** (на **19.2%** меньше в одном контрольном прогоне); прибыли 161 и 167 автомобилей. Это демонстрация, а не подтверждение устойчивого улучшения: необходимы повторные проверки на нескольких seeds, спросах и сетях.

Посмотреть движение учебной сети:

```sh
sumo-gui -c examples/signal_demo/demo.sumocfg
```

Посмотреть работу сохранённой RL-политики в SUMO GUI (без нового обучения):

```sh
python sumo/rl_signals.py --play-policy examples/rl_result/policy.json --gui --output runs/replay
```

Для воспроизведения другой политики задайте те же диапазоны и шаг, что использовались при обучении. Эксперимент поддерживает один светофор без пешеходов. Сеть с переходами отклоняется явно: пешеходные ограничения пока не реализованы. Пример работает в симуляторе и не выдаёт план для реального контроллера.

## Генетический алгоритм сохранён

```sh
python sumo/optimize_traffic_lights.py --green-min 15 --green-max 60 --generations 5 --seed 42
```

Здесь настраиваются только зелёные; жёлтые и пешеходные фазы остаются исходными. Проекция после генерации/скрещивания/мутации сохраняет сумму зелёных и диапазоны. Если ограничения несовместимы с длиной цикла, выводится ошибка. Невалидный исходный план не может попасть в итог как «лучший». Для этого скрипта нужна текущая сеть с `tlLogic`; учебная сеть RL хранится отдельно и не перезаписывает пользовательскую сеть.
