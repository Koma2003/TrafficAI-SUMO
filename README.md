# TrafficAI-SUMO

Приложение для анализа инфраструктуры выбранной области OpenStreetMap и моделирования отдельного перекрёстка в SUMO.

## Возможности

- Выбор прямоугольной области на карте и отчёт по зданиям, магазинам, социальной инфраструктуре и другим объектам OSM.
- Построение упрощённой модели перекрёстка, редактирование полос, манёвров и интенсивностей.
- Подбор статического светофорного плана с ограничениями непрерывного зелёного, жёлтого и красного каждого направления. Фаза «всем красный» настраивается отдельно.
- Отдельное RL-обучение на учебном автомобильном перекрёстке и сравнение с фиксированными планами.

Геометрия и отчёт строятся без LLM; API-ключ не требуется. Отчёт не прогнозирует население, посещаемость или пешеходный спрос.

## Установка и запуск

Проверено на Windows, Python 3.12 и SUMO 1.28.0. Требуется Python 3.10+; команды `sumo`, `sumo-gui`, `netconvert` должны быть доступны в PATH.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -E -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -E -X utf8 ui/control_panel.py
```

Для быстрого обучения и подбора можно установить `libsumo` той же версии, что SUMO. Для SUMO 1.28.0:

```powershell
.\.venv\Scripts\python.exe -E -m pip install libsumo==1.28.0
```

Без libsumo используется TraCI; расчёт может быть медленнее. Ключ `-E` исключает влияние системного PYTHONPATH, `-X utf8` обеспечивает вывод кириллицы в дочерних процессах.

## Границы модели

Поддерживается одна статическая программа одного светофора. Сеть и программы SUMO — упрощённая модель; интенсивности примера демонстрационные, не натурные измерения. Пешеходные маршруты сохраняются, но стоимость оптимизации учитывает автомобильные очереди и ожидание въезда. RL работает отдельно, на сети без пешеходов; улучшение относительно фиксированного управления не гарантируется.

Геоданные: © OpenStreetMap contributors, ODbL. Новая загрузка области требует интернета; при недоступности Overpass используется OSM Map API. Кэш хранится 24 часа. Локальные расчёты сохраняются в `runs/` и не публикуются автоматически.
